InspiCrete Terminal Vision（略称：ICTV）は、C++ で開発されている実験的な動画プレーヤーです。ローカルの動画ファイルをリアルタイムでフルカラーの ASCII アートに変換し、ターミナルウィンドウ上に直接描画することを目指しています。

一般的な動画プレーヤーがピクセルによって映像を表示するのに対し、ICTV は文字と 24 ビット RGB のフルカラーを用いて動画像を再現します。これにより、ターミナルならではの軽量で個性的、かつ視覚的な表現力を備えた動画再生体験を提供します。

> すべてのフレームを、文字で織りなす世界へ。

## ✨ 主な機能

- **フルカラー ASCII 動画** — 動画の各フレームを、24 ビット RGB のフルカラーに対応した高精細な ASCII アートに変換します。
- **リアルタイム動画再生** — 動画のタイムスタンプに基づいてフレームをデコード・描画し、連続した再生を実現します。
- **リアルタイム再生プログレスバー** — ターミナル下部に再生位置、経過時間、動画の総再生時間を表示します。
- **フレームレートの監視** — 実際の描画フレームレートと元動画のフレームレートを表示します。
- **ハードウェア・実行状態の監視** — CPU 使用率、メモリ使用量、解像度、デコーダー、ハードウェアアクセラレーションの状態など、取得可能なシステム情報を表示します。
- **ネイティブなターミナル体験** — 映像表示領域と下部のステータスバーを分離し、見やすく整理されたレイアウトを実現します。
- **クロスプラットフォーム設計** — Windows、Linux、macOS を対象プラットフォームとしています。
- **パフォーマンスを重視した設計** — 不要なターミナル出力やメモリコピーを可能な限り削減します。

本プロジェクトは現在、開発を進めている段階です。未実装の機能は今後の実装予定であり、現行バージョンで利用できることを意味するものではありません。

## 🚀 クイックスタート

### 動作・開発環境

想定している開発環境は以下のとおりです。

- C++20 に対応したコンパイラ
- CMake
- Git
- FFmpeg の開発用ライブラリ
- ANSI/VT 制御シーケンスに対応したターミナル（24 ビットのフルカラー表示に対応していることを推奨）

### ビルド方法

初期のビルド設定が完了した段階では、以下のコマンドでビルドできる予定です。

```bash
git clone https://github.com/yoizuki-hy/InspiCrete-Terminal-Vision
cd InspiCrete-Terminal-Vision

cmake -S . -B build
cmake --build build
```

### 使用方法

以下のコマンドラインインターフェースを提供する予定です。

```bash
# ビルドディレクトリへ移動
cd ./build

# 動画の最初のフレームを表示
./ictv.exe --first-frame "path/test.mp4"

# 動画を再生
./ictv.exe video.mp4

# または、ファイルパスを指定
./ictv.exe "path/test.mkv"

# Half-Block モードで動画を再生
./ictv.exe --render-mode=half-block "path/test.mp4"

# ヘルプを表示
./ictv.exe --help

# バージョン情報を表示
./ictv.exe --version
```

上記は予定しているコマンドラインインターフェースです。対応する機能が未実装の場合、これらのコマンドは正常に動作しない可能性があります。

## ⌨️ 操作方法

以下の再生操作に対応する予定です。

| キー | 動作 |
|---|---|
| `Space` | 一時停止 / 再開 |
| `Q` | プレーヤーを終了 |
| `Esc` | プレーヤーを終了 |
| `A` | 5 秒巻き戻す |
| `D` | 5 秒早送りする |

マウス操作、クリックによるシーク、プログレスバーのドラッグ操作などについては、今後の開発状況に応じて導入を検討します。

## 🧩 プロジェクト構成

ICTV はモジュール化された設計を採用し、それぞれの責務を独立性の高いコンポーネントに分割しています。

- **CLI** — コマンドライン引数の解析と設定管理を担当します。
- **VideoDecoder** — 動画ストリームの処理と動画フレームのデコードを担当します。
- **AsciiConverter** — 文字のマッピング、輝度の調整、色変換を担当します。
- **TerminalRenderer** — ターミナルへの出力、インターフェースのレイアウト、描画バッファーの管理を担当します。
- **StatusBar** — 再生位置、フレームレート、動画情報、実行状態の表示を担当します。
- **SystemMonitor** — 各プラットフォーム固有のシステムパフォーマンス情報の収集を担当します。
- **PlaybackController** — 再生タイミング、入力処理、各モジュール間の連携を担当します。

全体の設計をシンプルかつ実用的に保ちながら、各モジュールのテスト容易性と保守性を確保することを目指しています。
