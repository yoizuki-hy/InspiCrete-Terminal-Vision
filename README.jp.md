# InspiCrete Terminal Vision

**カラフルな ASCII アートで動画を再生する、クロスプラットフォーム対応のターミナル動画プレーヤー。**

InspiCrete Terminal Vision（略称：ICTV）は、ローカルの動画ファイルをリアルタイムでカラー ASCII アートに変換し、ターミナル上で再生することを目指した、C++ 製の実験的な動画プレーヤーです。

一般的な動画プレーヤーが画面上にピクセルを描画するのに対し、ICTV は文字と 24 ビット RGB のフルカラーを用いて動画像を再現します。ターミナルならではの軽快さと、文字で映像を表現する独特のビジュアル体験を目指しています。

> すべてのフレームを、文字でできた世界へ。

## ✨ 主な機能

- **カラー ASCII 動画** — 24 ビット RGB のフルカラーに対応し、細部まで表現できる文字ベースの映像描画を目指します。
- **リアルタイム再生** — 動画のタイムスタンプに基づいてフレームをデコードし、再生タイミングを制御します。
- **リアルタイム進捗バー** — ターミナル最下部に再生位置、経過時間、動画の総再生時間を表示します。
- **FPS モニタリング** — 実際の描画 FPS と、動画ソースのフレームレートを表示します。
- **ハードウェア・実行状態の監視** — 取得可能な CPU 使用率、メモリ使用状況、解像度、デコーダー、ハードウェアアクセラレーションの状態などを表示します。
- **ターミナルに最適化された表示** — 動画表示領域とステータスバーを分離し、画面構成を整理します。
- **クロスプラットフォーム設計** — Windows、Linux、macOS での動作を目指します。
- **パフォーマンスを考慮した設計** — 不要なターミナル出力やメモリコピーを可能な限り削減します。

本プロジェクトは段階的に開発を進めています。未実装の機能は今後の実装予定であり、現時点で利用できることを保証するものではありません。

## 🛠️ 技術スタック

| 技術 | 用途 |
|---|---|
| C++20 | コア機能の実装 |
| CMake | ビルドシステム |
| FFmpeg | 動画コンテナの解析とデコード |
| ANSI/VT エスケープシーケンス | ターミナル制御と描画 |

依存関係を必要最小限に抑え、明確で保守しやすいモジュール構成を目指しています。

### 動作・開発環境

想定している開発環境は次のとおりです。

- C++20 に対応したコンパイラ
- CMake
- Git
- FFmpeg の開発用ライブラリ
- ANSI/VT エスケープシーケンスに対応したターミナル（24 ビットカラー対応を推奨）

### ビルド方法

初期のビルド設定が完成した後は、次の手順でビルドできる構成を目指しています。

```bash
git clone <repository-url>
cd InspiCreteTerminalVision

cmake -S . -B build
cmake --build build
```

`<repository-url>` は、実際の GitHub リポジトリの URL に置き換えてください。

### 使用方法

次のコマンドラインインターフェースを実装する予定です。

```bash
ictv video.mp4
ictv "path/to/my video.mkv"

ictv --help
ictv --version
```

これらは実装予定のコマンドです。対応する機能が実装されるまでは、正常に動作しない場合があります。

## ⌨️ 操作方法

マウスによる操作、クリックやドラッグによる再生位置の変更などは、今後の拡張機能として検討します。

## 🧩 アーキテクチャ

ICTV は、各機能の責務を分離したモジュール構成を採用する予定です。

- **CLI** — コマンドライン引数の解析と設定管理。
- **VideoDecoder** — 動画ストリームの処理とフレームのデコード。
- **AsciiConverter** — 文字マッピング、輝度処理、色変換。
- **TerminalRenderer** — ターミナルへの出力、画面レイアウト、描画バッファの管理。
- **StatusBar** — 再生進捗、FPS、動画情報、再生状態の表示。
- **SystemMonitor** — プラットフォームごとのシステム情報の取得。
- **PlaybackController** — 再生タイミング、入力処理、各モジュールの連携。

全体の構成をシンプルかつ実用的に保ちながら、各モジュールのテスト容易性と保守性を高めることを目指しています。
