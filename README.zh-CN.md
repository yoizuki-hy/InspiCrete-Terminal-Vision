InspiCrete Terminal Vision（简称 ICTV）是一款基于 C++ 开发的实验性视频播放器，旨在将本地视频文件实时转换为彩色 ASCII 字符画，并直接呈现在终端窗口中。

与传统视频播放器通过常规画面显示像素不同，ICTV 使用字符与 24 位 RGB 真彩色重现动态影像，为终端带来一种轻量、独特且富有视觉表现力的视频播放体验。

> 让每一帧画面，都成为字符构成的世界。

## ✨ 项目特性

- **彩色 ASCII 视频** —— 将视频帧转换为细节丰富的字符画，支持 24 位 RGB 真彩色。
- **实时视频播放** —— 基于视频时间戳解码并渲染画面，实现连续播放。
- **实时进度条** —— 在终端底部显示播放进度、已播放时间与视频总时长。
- **帧率监控** —— 同时展示实际渲染帧率与源视频帧率。
- **硬件与运行状态监控** —— 展示可获取的 CPU、内存、分辨率、解码器及硬件加速信息。
- **原生终端体验** —— 将视频画面与底部状态栏分离，保持界面布局清晰。
- **跨平台设计** —— 以 Windows、Linux 和 macOS 为目标平台。
- **面向性能的架构** —— 尽可能减少不必要的终端输出与内存复制。

项目正在逐步开发中。尚未实现的功能均属于计划内容，不代表当前版本已经具备相应能力。

## 🛠️ 技术栈

| 技术 | 用途 |
|---|---|
| C++20 | 核心功能开发 |
| CMake | 项目构建与管理 |
| FFmpeg | 视频封装解析与解码 |
| ANSI/VT 控制序列 | 终端控制与画面渲染 |
| 24 位 RGB | 彩色字符画渲染 |
| Catch2 | 单元测试，计划引入 |

项目致力于保持依赖精简、模块划分清晰，并在功能、性能与可维护性之间取得平衡。

## 🚀 快速开始

ICTV 目前仍处于开发阶段。待初始实现和依赖配置完成后，将进一步完善构建与运行说明。

### 环境要求

计划使用的开发环境包括：

- 支持 C++20 的编译器
- CMake
- Git
- FFmpeg 开发库
- 支持 ANSI/VT 控制序列的终端，建议支持 24 位真彩色

### 编译项目

初始构建配置完成后，预期可以通过以下命令进行构建：

```bash
git clone <repository-url>
cd InspiCreteTerminalVision

cmake -S . -B build
cmake --build build
```

请将 `<repository-url>` 替换为实际的 GitHub 仓库地址。

### 使用方法

计划提供以下命令行接口：

```bash
ictv video.mp4
ictv "path/to/my video.mkv"

ictv --help
ictv --version
```

以上为预期的命令行接口。相关功能尚未实现时，这些命令可能无法正常运行。

## ⌨️ 操作说明

计划支持以下播放控制：

| 按键 | 功能 |
|---|---|

## 🧩 项目架构

ICTV 采用模块化设计，将不同职责划分为相对独立的组件：

- **CLI** —— 负责命令行参数解析与配置管理。
- **VideoDecoder** —— 负责视频流处理与视频帧解码。
- **AsciiConverter** —— 负责字符映射、亮度处理与颜色转换。
- **TerminalRenderer** —— 负责终端输出、界面布局与渲染缓冲。
- **StatusBar** —— 负责播放进度、帧率、视频信息与状态显示。
- **SystemMonitor** —— 负责平台相关的系统运行指标采集。
- **PlaybackController** —— 负责播放时序、输入处理与模块协调。

项目希望在保证整体设计简洁、实用的前提下，让各模块具备良好的可测试性与可维护性。
